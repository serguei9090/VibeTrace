# Services

## Overview

Domain service layer for VibeTrace. Holds the pure-Python workflows that sit between the indexer database and the CLI, MCP server, and REST API: graph traversal and impact analysis, execution-path tracing, code slicing, call-tree construction, hybrid search, caller guarding, coverage gating, unified review, predictive test selection, architectural split auditing, AST refactoring, saved trace persistence, reindex orchestration, repo-map generation, and token-budgeted context bundling.

## Invariants

- `ensure_index_fresh` is debounced per project root by `debounce_seconds` (default 2.0) using the module-level `_LAST_SYNC_CHECK` map; it returns `False` without reindexing inside the debounce window [src/vibetrace/services/graph_service.py:ensure_index_fresh].
- `ensure_index_fresh` triggers a reindex when the Git SHA changed, when the delta contains changed or deleted files, or when the index has never been indexed (`last_sha` empty); a `"non-git"` marker with no current SHA is a no-op [src/vibetrace/services/graph_service.py:ensure_index_fresh].
- `get_context_for_path` resolves the project root by walking up for `.git`, `pyproject.toml`, `package.json`, `Cargo.toml`, `go.mod`, `.vibetrace.toml`, `vibetrace.toml`, `.vibetrace`, or `vibetrace_context`; `VIBETRACE_PROJECT_ROOT` is used when no marker is found [src/vibetrace/services/graph_service.py:get_context_for_path].
- `get_context_for_path` prefers `.vibetrace/vibetrace.db`, then the configured database path, then `.vibetrace/vibetrace.db`, and finally `vibetrace_context/vibetrace.db` [src/vibetrace/services/graph_service.py:get_context_for_path].
- `normalize_path` returns a project-root-relative path with forward slashes; when the file is outside the root it falls back to the absolute resolved path [src/vibetrace/services/graph_service.py:normalize_path].
- `safe_str` replaces emoji and box-drawing characters only on Windows when stdout cannot encode them [src/vibetrace/services/graph_service.py:safe_str].
- `GraphTraverser.traverse` stops when `depth > max_depth`, emits a cycle marker when the node is already in the ancestor path, and emits an "already traversed" marker for nodes visited in another branch [src/vibetrace/services/graph_service.py:GraphTraverser.traverse].
- `build_call_stack` defaults to relation types `("calls", "routes")` and clears the visited set between the caller and callee passes so both directions are explored independently [src/vibetrace/services/graph_service.py:build_call_stack].
- `compute_impact_analysis` computes at most 3 transitive levels and counts only dependents in a different file than the analyzed file [src/vibetrace/services/graph_service.py:compute_impact_analysis].
- `analyze_file_dependencies` classifies imports into `internal`, `third_party`, and `stdlib` using `file_path == "external"` as the external marker, and detects circular imports by checking whether any internal dependency imports the analyzed file back [src/vibetrace/services/graph_service.py:analyze_file_dependencies].
- `build_call_tree` defaults to `max_depth=3`, relation types `("calls", "routes")`, and a hard ceiling of `max_nodes=500`; a node already in the ancestor path is emitted with `is_cycle=True` and not expanded [src/vibetrace/services/call_tree_service.py:build_call_tree].
- `build_call_tree` orders children by `call_line` (missing lines sort last) and then by name [src/vibetrace/services/call_tree_service.py:build_call_tree].
- `format_call_tree_md` falls back to ASCII connectors when stdout cannot encode the Unicode tree characters [src/vibetrace/services/call_tree_service.py:format_call_tree_md].
- `CallerGuardService.get_caller_guard` counts only incoming `calls` and `routes` relations; risk is `LOW` for 0-3 callers, `MEDIUM` for 4-10, and `HIGH` above 10 [src/vibetrace/services/caller_guard.py:CallerGuardService.get_caller_guard].
- `CallerGuardService.get_caller_guard` disambiguates multiple same-name symbols by incoming caller count and centrality, and lists the rejected candidates in `alternative_candidates` [src/vibetrace/services/caller_guard.py:CallerGuardService.get_caller_guard].
- `CallerGuardService.get_caller_guard` sorts call sites deterministically by file path and call line, and deduplicates by `(caller id, file, line)` [src/vibetrace/services/caller_guard.py:CallerGuardService.get_caller_guard].
- `CallerGuardService.get_staged_caller_guard` skips nodes of kind `module` or `file`, and sets `signature_changed=False` when the diff only touches the function body; in that case the advisory states the change is non-breaking [src/vibetrace/services/caller_guard.py:CallerGuardService.get_staged_caller_guard].
- `parse_git_diff_line_ranges` derives modified ranges from the `+` side of `@@` hunk headers, treating a missing count as 1 line [src/vibetrace/services/caller_guard.py:parse_git_diff_line_ranges].
- `load_quality_gate_config` reads `[quality_gate] min_coverage` and `enforce_coverage` from the project config, defaulting to `(80.0, False)` when the file is missing or unparsable [src/vibetrace/services/coverage_service.py:load_quality_gate_config].
- `CoverageService.evaluate_coverage_gate` propagates 3 hops forward from every test function to mark covered symbols; a symbol counts as covered when its id or its name is in the covered set [src/vibetrace/services/coverage_service.py:CoverageService.evaluate_coverage_gate].
- `CoverageService.evaluate_coverage_gate` excludes test symbols, files, and symbols whose name starts with `_` from the coverage target set [src/vibetrace/services/coverage_service.py:CoverageService.evaluate_coverage_gate].
- `CoverageService.evaluate_coverage_gate` prefers external line coverage (`coverage.xml` or `lcov.info`) over the AST call-graph percentage when it is available; the coverage source becomes `hybrid (ast + <file>)` [src/vibetrace/services/coverage_service.py:CoverageService.evaluate_coverage_gate].
- `CoverageService.evaluate_coverage_gate` status is `PASSED` at or above the threshold, `ADVISORY` below it when not enforced, `FAILED` below it when enforced, and `N/A` when no coverage could be computed [src/vibetrace/services/coverage_service.py:CoverageService.evaluate_coverage_gate].
- `DiagnoseService.diagnose_symbol` defaults to `max_depth=2` and injects at most 300 documentation tokens via `max_doc_tokens=300` [src/vibetrace/services/diagnose_service.py:DiagnoseService.diagnose_symbol].
- `DiagnoseService.diagnose_symbol` computes the blast radius as `L1_direct` (direct callers) and `L2_secondary` (callers of the direct callers), excluding the target symbol itself [src/vibetrace/services/diagnose_service.py:DiagnoseService.diagnose_symbol].
- `DiagnoseService.diagnose_symbol` estimates payload size as code tokens plus documentation tokens plus 15 tokens per caller [src/vibetrace/services/diagnose_service.py:DiagnoseService.diagnose_symbol].
- `hybrid_search` fuses four streams with weights AST 1.2, semantic 1.1, FTS5 1.0, and centrality 0.8, using `RRF_Score(d) = sum(w_s / (rrf_k + rank_s(d)))` with `rrf_k=60` by default [src/vibetrace/services/hybrid_search.py:hybrid_search].
- `hybrid_search` returns an empty list for an empty query, `limit <= 0`, or `offset < 0`; the candidate pool is `max((limit + offset) * 2, 30)` rows per stream [src/vibetrace/services/hybrid_search.py:hybrid_search].
- `hybrid_search` breaks score ties deterministically by centrality, file path, start line, and name [src/vibetrace/services/hybrid_search.py:hybrid_search].
- `hybrid_search` degrades gracefully to three streams when the embedding engine is unavailable or `search_semantic` raises [src/vibetrace/services/hybrid_search.py:hybrid_search].
- `is_stdlib_import` resolves the standard library by file extension (`.py`, `.go`, `.js`/`.jsx`/`.ts`/`.tsx`/`.mjs`/`.cjs`, `.rs`, `.java`, `.rb`) and always treats `node:` prefixed imports as standard library [src/vibetrace/services/stdlib_registry.py:is_stdlib_import].
- `get_python_stdlib_names` prefers `sys.stdlib_module_names` and falls back to the `FALLBACK_PY_STDLIB` set [src/vibetrace/services/stdlib_registry.py:get_python_stdlib_names].
- `PredictiveTestService.resolve_impacted_tests` traverses the reverse call graph up to `max_hops` (default 6) and follows relation types `calls`, `call`, `invokes`, and `references` [src/vibetrace/services/predictive_test_service.py:PredictiveTestService.resolve_impacted_tests].
- `PredictiveTestService.resolve_impacted_tests` includes a modified symbol directly when it is already a test, recorded with `hops=0` [src/vibetrace/services/predictive_test_service.py:PredictiveTestService.resolve_impacted_tests].
- `PredictiveTestService._build_runner_args` selects `uv run python -m pytest` when `uv` is on PATH, otherwise plain `pytest`; JavaScript and TypeScript tests use `bun test`, Rust uses `cargo test` [src/vibetrace/services/predictive_test_service.py:PredictiveTestService._build_runner_args].
- `RefactorService._analyze_block_lifetimes` rejects a block containing `yield`/`yield from`, `nonlocal` declarations, `break`/`continue` targeting an outer loop, or `return` statements [src/vibetrace/services/refactor_service.py:RefactorService._analyze_block_lifetimes].
- `RefactorService._analyze_block_lifetimes` computes inputs as variables read in the block that were defined before it or are function parameters, and outputs as variables written in the block that are read afterwards; Python builtins are excluded from both [src/vibetrace/services/refactor_service.py:RefactorService._analyze_block_lifetimes].
- `RefactorService.suggest_split_candidates` requires a block complexity of at least 1 with a span of at least 4 lines, or a block complexity of at least 2 with a span of at least 6 lines, and sorts candidates by highest complexity reduction first [src/vibetrace/services/refactor_service.py:RefactorService.suggest_split_candidates].
- `RefactorService.build_refactor_plan` returns a plan with `can_auto_apply=False` and a populated `rejection_reason` instead of raising when the block fails the pre-flight lifetime checks [src/vibetrace/services/refactor_service.py:RefactorService.build_refactor_plan].
- `RefactorService.build_refactor_plan` defaults the helper name to `_<func_name>_helper` and raises `ValueError` when the requested line range contains no statements [src/vibetrace/services/refactor_service.py:RefactorService.build_refactor_plan].
- `RefactorService.apply_refactor_plan` refuses to write when `plan.can_auto_apply` is `False` [src/vibetrace/services/refactor_service.py:RefactorService.apply_refactor_plan].
- `ReindexService.execute_reindex` raises `PermissionError` when the target file resolves outside the project root and `FileNotFoundError` when it does not exist [src/vibetrace/services/reindex_service.py:ReindexService.execute_reindex].
- `ReindexService.execute_reindex` resolves the LSP mode from the project config when the flag is not set: `always` enables it, `auto` enables it only when an LSP command is available [src/vibetrace/services/reindex_service.py:ReindexService.execute_reindex].
- `ReindexService.execute_reindex` runs the documentation sync only for `scope == "local"` catalogs and reports an `embeddings_error` when the optional embeddings extra is not installed [src/vibetrace/services/reindex_service.py:ReindexService.execute_reindex].
- `RepoMapService.generate_budgeted_repo_map` includes only symbols of kind `function`, `class`, `method`, `endpoint`, `struct`, or `trait`, ordered by centrality descending, and stops adding symbols once the budget is exhausted [src/vibetrace/services/repo_map_service.py:RepoMapService.generate_budgeted_repo_map].
- `RepoMapService.generate_budgeted_repo_map` reserves 20 tokens of headroom for the pruning footer and floors the effective budget at 32 tokens [src/vibetrace/services/repo_map_service.py:RepoMapService.generate_budgeted_repo_map].
- `run_unified_review` normalizes the scope to `changed` unless the caller passes `full` [src/vibetrace/services/review_service.py:run_unified_review].
- `run_unified_review` counts a security finding as active only when its status is `UNAPPROVED` or `MODIFIED`, and a split as active only when its status is `NEW_UNAPPROVED`, `MODIFIED_CODE`, or `RISK` [src/vibetrace/services/review_service.py:run_unified_review].
- `run_unified_review` passes `complexity_threshold=15` to `QualityService.audit_project` and excludes test files from the quality audit [src/vibetrace/services/review_service.py:run_unified_review].
- `run_unified_review` reports `passed=True` only when there are no unapproved or modified security findings, no unapproved or modified quality findings, no new or modified splits, and the coverage gate passed [src/vibetrace/services/review_service.py:run_unified_review].
- `create_saved_trace` upserts on the `name` column, replacing description, endpoints, and depth, and raises `RuntimeError` when the row cannot be read back [src/vibetrace/services/saved_traces_service.py:create_saved_trace].
- `SavedTraceCreate.name` is bounded to 1..100 characters and `max_depth` to `1..20` (default 6); `SavedTrace.max_depth` defaults to 6 [src/vibetrace/services/saved_traces_service.py:SavedTraceCreate].
- `scan_architectural_splits` only considers nodes of kind `function`, `method`, or `endpoint` with at least 2 distinct outgoing `calls` or `routes` targets, excludes test files, and requires the branches to span at least 2 distinct target files [src/vibetrace/services/split_audit_service.py:scan_architectural_splits].
- `compute_symbol_code_hash` hashes the whitespace-stripped, non-empty source lines of the symbol range and returns the SHA-256 of an empty payload when the file or range is invalid [src/vibetrace/services/split_audit_service.py:compute_symbol_code_hash].
- `audit_splits` marks a split `APPROVED` when the recomputed code hash matches the baseline hash, `MODIFIED_CODE` when the baseline exists but the hash differs, and `NEW_UNAPPROVED` when there is no baseline record [src/vibetrace/services/split_audit_service.py:audit_splits].
- `record_split_approval` writes the baseline with a UTC ISO timestamp and indexes the record under the file-qualified name and the bare symbol [src/vibetrace/services/split_audit_service.py:record_split_approval].
- `read_file_lines` blocks path traversal: it raises `ValueError` when the resolved path is not inside the project root, and `FileNotFoundError` when the file does not exist [src/vibetrace/services/trace_service.py:read_file_lines].
- `get_code_slice` returns `found=False` when no node matches; it falls back to `search_ast_exact_or_prefix` only when no file path was supplied [src/vibetrace/services/trace_service.py:get_code_slice].
- `get_code_slice` collects callee contracts only for relation types `calls` and `routes`, deduplicated by `(neighbor id, call line)`, and attaches linked documentation capped at `max_doc_tokens=300` [src/vibetrace/services/trace_service.py:get_code_slice].
- `trace_execution_path` accepts `engine` values `bfs` (bidirectional BFS) and `cte` (native SQLite recursive CTE); the CTE path stops at `max_depth` hops [src/vibetrace/services/trace_service.py:trace_execution_path].
- `get_downstream_reachable_symbols` defaults to `max_depth=8` and excludes the starting symbol from the result set [src/vibetrace/services/trace_service.py:get_downstream_reachable_symbols].
- `VibeBundleService.assemble_bundle` raises the budget floor to 500 tokens and allocates approximately 40% to the code slice, 25% to documentation, and 20% to sibling test context [src/vibetrace/services/vibe_bundle.py:VibeBundleService.assemble_bundle].
- `VibeBundleService.assemble_bundle` infers the target symbol from the intent with `hybrid_search` when `target_symbol` is not supplied, taking the top hit [src/vibetrace/services/vibe_bundle.py:VibeBundleService.assemble_bundle].
- `VibeBundleService.assemble_bundle` searches local documentation first and falls back to the global scope when the local search returns nothing [src/vibetrace/services/vibe_bundle.py:VibeBundleService.assemble_bundle].
- `truncate_to_tokens` appends the notice `... [truncated to fit token budget]` and shrinks the retained prefix until the estimate fits the budget [src/vibetrace/services/vibe_bundle.py:truncate_to_tokens].
- `AdaptiveSessionManager.get_session_path` sanitizes the session id to alphanumerics, `-`, and `_` before building the file name [src/vibetrace/services/vibe_bundle.py:AdaptiveSessionManager.get_session_path].

## Side Effects

- `ensure_index_fresh` may run `reindex_all`, which rewrites the index database [src/vibetrace/services/graph_service.py:ensure_index_fresh].
- `get_context_for_path` creates the database parent directory and opens an `IndexerDB` connection; it also triggers the auto-sync reindex when `cfg.indexer.auto_sync` is enabled [src/vibetrace/services/graph_service.py:get_context_for_path].
- `CallerGuardService.get_staged_caller_guard` shells out to `git diff --cached -U0` when no diff text is supplied [src/vibetrace/services/caller_guard.py:CallerGuardService.get_staged_caller_guard].
- `CallerGuardService.get_caller_guard` reads caller source lines from disk to build the call snippet [src/vibetrace/services/caller_guard.py:CallerGuardService.get_caller_guard].
- `_parse_external_line_coverage` reads `coverage.xml`, `lcov.info`, or `coverage/lcov.info` from the project root [src/vibetrace/services/coverage_service.py:_parse_external_line_coverage].
- `PredictiveTestService.resolve_impacted_tests` shells out to Git to collect modified line ranges when `target_symbols` is not supplied [src/vibetrace/services/predictive_test_service.py:get_git_modified_ranges].
- `PredictiveTestService.execute_impacted_tests` runs the selected test runner as a subprocess; it is skipped entirely when no impacted tests were found [src/vibetrace/services/predictive_test_service.py:PredictiveTestService.execute_impacted_tests].
- `RefactorService.apply_refactor_plan` writes the refactored full source back to the target file with UTF-8 encoding [src/vibetrace/services/refactor_service.py:RefactorService.apply_refactor_plan].
- `ReindexService.execute_reindex` rewrites the index database, prunes orphaned graph edges, purges orphaned vector embeddings, and may write new symbol embeddings [src/vibetrace/services/reindex_service.py:ReindexService.execute_reindex].
- `ReindexService.execute_reindex` indexes local documentation catalogs into the documentation store and prints progress lines to stdout/stderr unless `is_json` is set [src/vibetrace/services/reindex_service.py:ReindexService.execute_reindex].
- `run_unified_review` shells out to `git status --porcelain` and `git diff HEAD -U0` to detect changed files [src/vibetrace/services/review_service.py:_detect_git_changed_files].
- `run_unified_review` invokes the security and quality audit engines, which may write a SARIF file when `sarif_file` is supplied [src/vibetrace/services/review_service.py:run_unified_review].
- `create_saved_trace`, `delete_saved_trace`, and `delete_saved_trace_by_name` write to the `saved_traces` table and commit the transaction; the write helpers are wrapped in `with_write_retry` [src/vibetrace/services/saved_traces_service.py:create_saved_trace].
- `get_splits_toml_path` creates the `.vibetrace` directory; `save_split_baseline` overwrites `.vibetrace/splits.toml` [src/vibetrace/services/split_audit_service.py:get_splits_toml_path].
- `record_split_approval` writes the approval record to `.vibetrace/splits.toml` [src/vibetrace/services/split_audit_service.py:record_split_approval].
- `notify_ui_focus` POSTs a JSON `agent_focus` event to `/api/agent-focus` on the local Map Room server (`VIBETRACE_SERVER_URL` or `http://127.0.0.1:<VIBETRACE_PORT>`) from a daemon thread with a 0.15s timeout; failures are swallowed [src/vibetrace/services/trace_service.py:notify_ui_focus].
- `read_file_lines` reads source files from disk and returns them as numbered lines [src/vibetrace/services/trace_service.py:read_file_lines].
- `AdaptiveSessionManager.get_session_dir` creates `.vibetrace/sessions`; `save_session` writes the session state as JSON and `reset_session` deletes the session file [src/vibetrace/services/vibe_bundle.py:AdaptiveSessionManager.get_session_dir].
- `hybrid_search` reads the embedding index and may load the embedding model for the semantic stream [src/vibetrace/services/hybrid_search.py:hybrid_search].
