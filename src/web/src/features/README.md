# Features

## Overview

Feature grouping for the VibeGraph web client. This directory holds no direct source files; each feature is documented in its own subdirectory contract.

## Subdirectories & Boundaries

- [`dashboard`](./dashboard/README.md) - Unified AI Quality Gate: review report KPIs, split and security approval, coverage and remediation triage.
- [`docs`](./docs/README.md) - Documentation RAG: catalog indexing, scoped semantic search, chunk reading.
- [`map-room`](./map-room/README.md) - Architecture map: graph domain types, state hooks, ELK/WebGPU layout utilities, and map room components.
