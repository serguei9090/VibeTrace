# Dashboard

## Overview

Feature grouping for the Unified AI Quality Gate dashboard. This directory holds no direct source files; the dashboard implementation lives in its `components` subdirectory.

## Subdirectories & Boundaries

- [`components`](./components/README.md) - `DashboardView` (review report, KPI cards, approval actions) and `DashboardTriageTables` (coverage, splits, security, and remediation tabs).
